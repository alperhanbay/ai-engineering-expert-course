# Capstone Guide

## Project

Build a **Production-Style AI Knowledge and Workflow Assistant**.

## Goal

The capstone should demonstrate that you can design, implement, evaluate, secure, and explain a real AI engineering system.

## Required Milestones

| Milestone | Deliverable |
| --- | --- |
| M1 | API skeleton and SQL schema |
| M2 | Document ingestion and chunking |
| M3 | Embeddings and vector database |
| M4 | Basic RAG answer with citations |
| M5 | Hybrid retrieval and reranking |
| M6 | Evaluation suite and golden dataset |
| M7 | Agent workflow with tools |
| M8 | Monitoring, logging, and security design |
| M9 | Demo script and interview pack |

## Definition of Done

- The API can be run locally.
- Documents can be ingested.
- Chunks include metadata.
- Vector search works with filters.
- RAG answers include citations.
- Unsupported questions return safe no-answer behavior.
- Retrieval experiments are documented.
- Evaluation cases and results are included.
- Agent tool workflows are defined.
- Security controls are documented.
- Incident response and rollback are documented.
