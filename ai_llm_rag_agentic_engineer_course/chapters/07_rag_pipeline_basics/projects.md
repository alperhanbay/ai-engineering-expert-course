# Projects: RAG Pipeline Basics

## Project 1: End-to-End Basic RAG

Build a basic RAG system with:

- document loader;
- text cleaner;
- chunker;
- metadata extractor;
- embedding generator;
- vector index;
- retriever;
- prompt builder;
- answer generator;
- citation output;
- request logger.

Acceptance criteria:

- at least 20 documents or synthetic documents;
- citations include source and chunk ID;
- no-answer behavior works;
- request trace is saved.

## Project 2: Chunk Inspection Report

Create a report with:

- 20 sample chunks;
- token counts;
- metadata;
- quality notes;
- broken chunks;
- fixes.

## Project 3: Citation Test

Create 20 questions and verify:

- answer is supported;
- citation points to the correct chunk;
- no-answer is returned when context is missing.
