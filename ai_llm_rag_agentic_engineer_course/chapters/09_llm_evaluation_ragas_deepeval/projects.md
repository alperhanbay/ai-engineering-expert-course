# Projects: LLM and RAG Evaluation

## Project 1: Golden Dataset Builder

Create at least 50 evaluation cases.

Each case must include:

- question;
- expected answer;
- reference context IDs;
- difficulty;
- risk level;
- domain;
- expected no-answer flag.

## Project 2: RAG Evaluation Runner

Build an evaluation runner that:

- runs the RAG pipeline on all cases;
- stores retrieved chunks;
- stores generated answers;
- computes retrieval metrics;
- computes generation metrics;
- writes a report.

## Project 3: Human Review Workflow

Create a human review rubric and review form.

Include:

- accuracy;
- citation correctness;
- completeness;
- safety;
- clarity;
- action recommendation.

## Project 4: Release Gate

Define release thresholds for:

- retrieval recall;
- faithfulness;
- citation correctness;
- critical error count;
- latency.
