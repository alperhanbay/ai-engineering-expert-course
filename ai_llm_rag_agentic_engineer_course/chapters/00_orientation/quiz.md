# Quiz: Orientation and Expert Roadmap

## Multiple Choice

1. What is the most accurate description of production AI engineering?
   - A. Writing prompts for a chatbot
   - B. Training large foundation models from scratch
   - C. Building reliable systems around models, data, APIs, evaluation, and operations
   - D. Only building notebooks

2. In a RAG system, what usually happens before answer generation?
   - A. Retrieval of relevant context
   - B. User authentication is always skipped
   - C. The model is fine-tuned every time
   - D. The vector database writes the final answer

3. Why are agents riskier than plain chatbots?
   - A. They cannot use memory
   - B. They may call tools and take actions
   - C. They do not use language models
   - D. They cannot be logged

4. What is the best evidence that you understand a topic deeply?
   - A. You know one library name
   - B. You can repeat a definition
   - C. You can implement it, evaluate it, debug it, and explain tradeoffs
   - D. You watched a video about it

5. Which item belongs to production operations?
   - A. Request tracing
   - B. Token/cost tracking
   - C. Incident response
   - D. All of the above

## Fill in the Blanks

4. The `my_work/` folder is used to store your own notes, code, answers, and ________.
5. Expert learning requires conceptual understanding, implementation skill, and production ________.
