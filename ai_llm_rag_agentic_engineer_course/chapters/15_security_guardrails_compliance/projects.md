# Projects: Security, Guardrails, and Compliance

## Project 1: Threat Model

Create a threat model for your capstone.

Include:

- assets;
- actors;
- trust boundaries;
- threats;
- controls;
- residual risk.

## Project 2: Guardrail Test Suite

Create at least 30 security test cases:

- prompt injection;
- system prompt extraction;
- unauthorized document access;
- PII request;
- unsafe tool action;
- missing citation;
- unsupported high-risk answer;
- cross-tenant retrieval;
- malicious tool output;
- cost abuse.

## Project 3: Audit Log Design

Design audit logs for:

- document upload;
- chunk retrieval;
- answer generation;
- tool call;
- blocked action;
- human approval.

## Project 4: PII Handling Policy

Write policy for:

- detection;
- masking;
- logging;
