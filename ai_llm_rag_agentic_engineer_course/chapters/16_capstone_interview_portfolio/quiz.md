# Quiz: Capstone and Interview Readiness

## Multiple Choice

1. What is the main purpose of the capstone?
   - A. Demonstrate an integrated production-style AI system
   - B. Show one prompt only
   - C. Avoid evaluation
   - D. Replace all documentation

2. What should a portfolio README include?
   - A. Architecture, RAG pipeline, evaluation, monitoring, security, and tradeoffs
   - B. Only a screenshot
   - C. Only a model name
   - D. Only a Docker command

3. What is a strong interview answer built around?
   - A. Problem, constraints, architecture, decisions, evaluation, production, tradeoffs
   - B. Only tool names
   - C. Only opinions
   - D. Only buzzwords

4. What should be included in final review?
   - A. Limitations and failure analysis
   - B. Only success cases
   - C. No sources
   - D. Hidden assumptions

5. Which capability is required for production-style readiness?
   - A. rollback strategy
   - B. evaluation suite
   - C. security controls
   - D. all of the above

## Fill in the Blanks

1. The capstone should demonstrate working artifacts and engineering ________.
2. A strong README should make the project ________ by someone else.
3. Evaluation evidence should include metrics, failed cases, and ________ analysis.
4. Tradeoffs explain what you chose and ________.
5. Security documentation should include guardrails, audit logs, and ________ handling.

## Short Answer

1. Write a 90-second capstone pitch.
2. List the top five tradeoffs in your capstone.
3. Explain how you would debug a sudden answer quality drop.
