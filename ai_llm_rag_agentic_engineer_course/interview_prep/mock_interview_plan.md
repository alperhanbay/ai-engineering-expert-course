# Mock Interview Plan

## 10-Day Sprint

### Day 1: Core Pitch

- 90-second introduction
- Capstone problem
- Why this field fits your skill set

### Day 2: RAG Deep Dive

- Explain the pipeline
- Defend chunking decisions
- Debug retrieval failures

### Day 3: Vector Search

- Embedding model selection
- Vector DB tradeoffs
- Metadata filtering and multi-tenant risk

### Day 4: Advanced RAG

- Hybrid search
- Reranking
- Query routing
- Incremental indexing

### Day 5: Evaluation

- Golden dataset
- RAGAS/DeepEval
- Human review
- Regression gate

### Day 6: Agentic AI

- Stateful workflow
- Tool use
- Memory
- Human approval

### Day 7: Production

- Monitoring
- Logging
- Incident response
- Rollback

### Day 8: Optimization

- Prompt caching
- KV-cache
- vLLM/TGI/Triton
- Latency budget

### Day 9: Security and Compliance

- PII
- Access control
- Audit logs
- Prompt injection
- Tool permissions

### Day 10: Full System Design

Practice a 45-minute design session:

1. Requirements
2. Architecture
3. Data model
4. RAG and retrieval
5. Agent workflow
6. Evaluation
7. Production operations
8. Security
9. Tradeoffs

## Answer Format

Use this structure:

```text
Definition:
  Short definition.

Why it matters:
  Production impact.

How I used it:
  Capstone example.

Tradeoff:
  Benefits and costs.

Failure mode:
  How it can break and how I would detect it.
```
