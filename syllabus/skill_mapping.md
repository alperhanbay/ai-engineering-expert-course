## Minimum Competence

- Build an API-backed RAG system.
- Store metadata, logs, feedback, and eval cases.
- Use a vector database with filters.
- Return grounded answers with citations.
- Run a basic evaluation set.
- Explain the architecture.

## Strong Applied Competence

- Compare retrieval strategies.
- Use hybrid search and reranking.
- Build a golden dataset and regression gate.
- Design a stateful agent workflow with tools.
- Add monitoring and incident response.
- Document security and compliance controls.

## Expert Competence

- Design systems independent of a single framework.
- Explain tradeoffs across quality, latency, cost, security, and operations.
- Build failure taxonomies and debug production incidents.
- Create domain-specific evaluation rubrics.
- Decide between RAG, fine-tuning, smaller classifiers, and tool workflows.
- Teach the concepts clearly with implementation evidence.
