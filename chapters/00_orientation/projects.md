# Projects: Orientation and Expert Roadmap

## Project 1: Personal Expert Skill Map

Create `my_work/expert_skill_map.md`.

Include:

- current level for each chapter;
- target level;
- evidence you need to produce;
- biggest risks;
- weekly study hours;
- capstone domain.

Rubric:

- Beginner: a table of skills and gaps.
- Intermediate: clear evidence for each skill.
- Advanced: dependencies and sequence between skills.
- Expert: measurable milestones and review dates.
