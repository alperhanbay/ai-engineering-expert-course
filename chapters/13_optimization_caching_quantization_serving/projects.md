# Projects: Optimization, Caching, Quantization, and Serving

## Project 1: Latency Budget and Profiling

Instrument your RAG API and measure:

- API overhead;
- retrieval latency;
- reranking latency;
- model first-token latency;
- full response latency;
- logging overhead.

Create a bottleneck report.

## Project 2: Caching Strategy

Design caching for:

- system prompts;
- retrieval results;
- document summaries;
- embeddings;
- reranker scores.

For each cache, define:

- key;
- value;
- TTL;
- invalidation rule;
- security risk.

## Project 3: Serving Decision Matrix

- hosted API;

- TGI;
- Triton.

Criteria:

- cost;
- latency;
- operations burden;
- model support;
- scaling;
- compliance;
